# DINGLI_EXPLICACOES.md
**Documentação Operacional, Arquitetura do Motor e Diretrizes Pedagógicas por Par - Dìnglì**

---

## 1. Visão Geral e Arquitetura da Esteira

O ecossistema de geração de explicações pedagógicas do Dìnglì opera de forma 100% autônoma na nuvem via **Google Apps Script (GAS)**, integrado diretamente à API REST do **Supabase** e com gravação no **Google Drive** (`Explicacoes_Prontas/`), eliminando a necessidade de terminal local ou máquina ligada durante a produção em lote.

### 1.1 O Ciclo de Execução em Lote Único
1. **Lote de 30 Frases:** Cada tópico do curso (composto por exatamente 30 frases) é enviado em uma **única chamada** à API do Gemini (`TAMANHO_BLOCO = 30`). O modelo processa e devolve o JSON completo com as 30 explicações de uma só vez, eliminando o antigo fracionamento 6x5 e economizando chamadas de rede.
2. **Modelo Exclusivo:** O pipeline utiliza estritamente o modelo **`gemini-3.5-flash`** com saída estruturada forçada via `responseMimeType: "application/json"` e `temperature: 0.2`. Não há uso de fallbacks para modelos secundários.
3. **Resiliência e Tolerância a Falhas:**
   - **Alternância Imediata de Chaves (Multi-Key):** Suporte a um array de chaves (`GEMINI_API_KEYS`). Ao receber HTTP 429 (limite diário ou por minuto), o motor chaveia imediatamente para a chave seguinte em menos de 1 segundo sem esperas desnecessárias.
   - **Até 5 tentativas por lote:** O laço de repetição permite até 5 ciclos completos pelas chaves antes de declarar falha.
   - **Pausa Coordenada de 60 segundos:** Se todas as chaves configuradas retornarem HTTP 429 no mesmo ciclo, o script aguarda 60 segundos cravados para que a janela deslizante da API zere antes do próximo ciclo.
   - **Pausa de 20 segundos em instabilidades (HTTP 503 / erros de rede):** Em erros de servidor ou falhas temporárias de conexão, o motor aguarda 20 segundos antes de tentar novamente.
   - **Trava de Segurança do Apps Script:** Monitoramento do tempo limite de 6 minutos (`360000 ms`) para evitar interrupções forçadas pelo Google.
4. **Auto-Recuperação na Planilha:** Na inicialização de cada rodada, o script varre a planilha e resgata qualquer linha que tenha ficado travada em `Em Processamento` ou com erro, resetando seu status automaticamente para `Pendente` com preenchimento em vermelho claro (`#f4cccc`).

### 1.2 Dimensionamento de Frequência e Cotas
- **Tempo médio de processamento:** ~55 a 65 segundos por tópico (30 frases).
- **Gatilho de 15 minutos:** Processa ~96 tópicos/dia (~2.880 frases/dia). Atinge o teto diário de 90 minutos de execução de gatilhos do Apps Script (contas `@gmail.com`) no final da noite, entregando entre 85 e 90 tópicos concluídos diariamente.
- **Gatilho de 30 minutos:** Processa 48 tópicos/dia (~1.440 frases/dia), consumindo ~48 minutos diários do Apps Script e mantendo folga total de tokens para concorrência com processamentos paralelos de aulas.

## 2. Modelagem de Dados no Supabase

O motor não utiliza regras estáticas em arquivos `.gs`. Toda a inteligência pedagógica, regras fonéticas e exemplos mestres são consumidos dinamicamente do Supabase via REST API.

### 2.1 Tabela `sentences`
Armazena o acervo central de frases do aplicativo:
- `id`: Identificador numérico único da frase.
- `level`: Nível de proficiência CEFR (`A1`, `A2`, `B1`, `B2`).
- `topic_[origem]`: Nome do tópico na língua materna do aluno (ex: `topic_pt`).
- Colunas de idioma: `en`, `pt`, `es`, `fr`, `it`, `ge` (e colunas específicas `zh` e `pi` para mandarim).
- **Endpoint de consulta:**
  `GET /rest/v1/sentences?level=eq.{nivel}&topic_{origem}=eq.{topico}&order=id.asc`

### 2.2 Tabela `matriz_pares`
Centraliza a parametrização didática e fonética de cada par de idiomas:
- `par` (Chave Primária): Código do par no formato `estudo_origem` (ex: `en_pt`, `pi_pt`, `fr_pt`, `es_pt`, `it_pt`, `ge_pt`).
- `nome_estudo`: Nome por extenso do idioma que está sendo ensinado (ex: `Inglês`, `Mandarim (Pinyin)`).
- `nome_origem`: Nome por extenso do idioma nativo do aluno (ex: `Português`).
- `instrucao_geral`: Prompt base com a persona do professor, regras rígidas de formatação dos campos e proibições terminológicas.
- `regras_foneticas`: O compêndio numerado de regras fonéticas aplicáveis àquele idioma sob a perspectiva da L1.
- `exemplo_mestre` (JSONB): Objeto JSON contendo a Frase Mestra Universal (Frase 1171) resolvida no padrão ouro para o par.
- **Endpoint de consulta:**
  `GET /rest/v1/matriz_pares?par=eq.{par}&select=nome_estudo,nome_origem,instrucao_geral,regras_foneticas,exemplo_mestre`

## 3. Diretrizes Pedagógicas Universais

Toda explicação pedagógica gerada deve seguir o tom de um amigo professor experiente, claro, acolhedor e totalmente livre de academicismos.

### 3.1 Proibição Absoluta de Jargões
- **Termos Gramaticais Banidos:** canônica, sintagma, elisão, clítico, próclise, ênclise, anafórico, deítico, pretérito, acusativo, dativo, genitivo, declinação, desinência, partícula aspectual, classificador nominal, cópula, oração subordinada, particípio, transitividade, adjunto adverbial, phrasal verb, conector subordinativo.
- **Termos Fonéticos Banidos:** fricativa, oclusiva, bilabial, alveolar, velar, glotal, liaison, schwa, flap, apócope, fonema, alofone, IPA.

### 3.2 Estrutura Rigorosa dos 3 Campos Gerados
Cada objeto de frase no JSON final deve conter estritamente as três chaves:

1. **`explanation` (A Lógica Mental da Frase):**
   - Parágrafo único contínuo (estritamente sem quebras de linha `\n`).
   - Revela como o nativo da L2 pensa a ideia em comparação direta com a L1, explicando ordem das palavras, conexões naturais e o sentido prático real (evitando traduções literais truncadas).
2. **`breakdown` (O Raio-X do Vocabulário):**
   - Array de objetos `[{"word": "...", "meaning": "..."}]`.
   - O campo `word` **nunca** deve conter pontuação no final (`?`, `.`, `!`, `,`).
   - Decompõe blocos significativos, termos compostos e preposições, detalhando cada pedaço e seu papel no sentido geral.
3. **`pronuncia` (Instruções Físicas + Transcrição Imediata):**
   - Texto corrido orientando a mecânica física da fala através dos 4 passos táteis:
     1. Ponto de contato (onde posicionar língua, dentes e lábios).
     2. Saída do ar e da voz (ar livre, sopro morno, retenção ou vibração).
     3. Trava da L1 (qual vício automático da língua materna deve ser bloqueado).
     4. Analogia sensorial simples do cotidiano.
   - Fechamento obrigatório na última linha com o comando da língua nativa:
     `Leia: [transcrição fonética adaptada]`

### 3.3 A Frase Mestra Universal (Frase 1171)
Para garantir coerência analítica e comparabilidade entre todos os 42 pares do Dìnglì, a **Frase 1171** (*O conceito de globalização alterou fundamentalmente a maneira como vivemos*) é o padrão ouro oficial adotado no Supabase para todos os pares homologados.

## 4. Travas Fonéticas por Par Homologado (L1 Português)

### 4.1 Inglês (`en_pt`)
- **4 Símbolos Obrigatórios com Instrução Tátil:**
  - `ı` (I curto): Queixo solto, sem sorriso, som rápido e frouxo entre 'e' e 'i' (`ship`, `live`).
  - `æ` (A aberto rasgado): Mandíbula aberta na vertical em 'A', cantos dos lábios puxados para os lados em 'É' (`cat`, `apple`).
  - `ə` (Som neutro): Mandíbula caída e língua relaxada, sopro curtíssimo e sem força (`about`, `problem`).
  - `3r` (Vogal do R central): Língua curvada para trás no céu da boca sem tocar em nada (`bird`, `work`).
- **Pares TH:** `th` surdo (língua entre os dentes assoprando ar puro) vs `dh` sonoro (língua entre os dentes vibrando a voz).
- **Consoantes Finais e S Mudo:** Consoantes finais cortam a seco sem 'i' de apoio (`stop`, `book`). Palavras com S inicial seguido de consoante começam direto no silvo do S, sem 'is-' ou 'es-' (`speak`, `study`).
- **Dark L e M Final:** No L final, a ponta da língua cola no céu da boca sem virar som de 'U' (`milk`, `hotel`). No M final, os lábios selam juntos a seco (`time`, `room`).

### 4.2 Mandarim Pinyin (`pi_pt`)
- **Proibição Estrita de 'E/Ê' em Som Gutural e Tom Neutro:** É terminantemente proibido grafar o som gutural posterior (/ɤ/) ou o tom neutro com 'e' ou 'ê'. Grafa-se obrigatoriamente: `da`, `la`, `ga`, `ka`, `rra` e `chán-ma` (para *shénme*).
- **Oposição de Aspiração:** B, D, G, Z, ZH e J são estalos secos sem ar e sem voz (som de P, T, C/K secos). Já P, T, K, C, CH e Q disparam um sopro explosivo de ar quente.
- **Série Retroflexa vs Palatal:** ZH, CH, SH e R articulam com a ponta da língua curvada para trás no céu da boca. J, Q e X articulam com sorriso tenso e língua espalmada na frente.
- **Vogal Ü de Bico:** Em *ju*, *qu*, *xu*, *yu*, lábios em bico firme de 'U' emitindo som de 'I' agudo por dentro, grafado com trema: `djü`, `tchü`, `xü`, `yü`.
- **Rimas com Vogal Oculta:** `-IAN` fecha em `iên`; `-IU` carrega 'o' oculto (`iôu`); `-UI` carrega 'e' central (`uêi`); `-UN` soa `uên`; `BO/PO/MO/FO` soam com transição labial em `uô`.
- **Corte Nasal Dental (-n) vs Ressonância Velar (-ng):** Em `-n` a ponta da língua trava atrás dos dentes da frente; em `-ng` a língua repousa embaixo e o dorso veda o fundo do céu da boca mole.

### 4.3 Francês (`fr_pt`)
- **4 Símbolos Obrigatórios com Instrução Tátil:**
  - `ü` (U francês): Lábios em bico apertado de assobio dizendo 'I' por dentro (`tu`, `rue`).
  - `ø` (EU fechado): Lábios em bico redondo de 'Ô' dizendo 'Ê' fechado por dentro (`peu`, `deux`).
  - `œ` (EU aberto): Lábios arredondados em 'Ó' dizendo 'É' aberto por dentro (`peur`, `sœur`).
  - `ə` (E mudo/relaxado): Lábios levemente arredondados, boca solta e som curto (`le`, `de`).
- **R de Garganta:** Raspar suavemente o fundo da garganta, sem vibrar a ponta da língua e sem raspar áspero (`paris`, `rouge`).
- **Vogais Nasais Puras:** Proibição de bater a língua ou fechar os lábios no final. O ar sai 100% pelo nariz: `ón` (an/am/en/em), `on` (on/om), `in` (in/im/ain/ein).
- **Consoantes Finais Mudas:** As letras D, T, P, S, X e Z no final das palavras morrem silenciosas.

### 4.4 Espanhol (`es_pt`)
- **Vogais Finais Fechadas:** O 'E' final nunca vira 'I' e o 'O' final nunca vira 'U'. Sustentam-se cravados em `ê` e `ô` (`nô-tche`, `a-mí-go`).
- **Proibição Total do Som de 'Z' (Abelha):** A letra S entre vogais é sempre sibilante e seca (`ka-sa` soando "kássa"). As letras Z e C (antes de E/I) soam estritamente como S puro internacional (`sa-pa-tô`, `kô-ra-són`).
- **J e G (antes de E/I) como Suspiro Aspirado:** Suspiro suave e morno direto do peito pela boca aberta (baforar no espelho), grafado estritamente com `h` (`ha-món`, `hên-tê`, `í-hô`). Proibido usar 'j' ou raspar garganta.
- **RR Vibrante na Ponta da Língua:** Tremor mecânico da ponta da língua no céu da boca ("motorzinho: brrr"), proibindo raspar a garganta.
- **Fusão B/V:** B e V têm o mesmo som labial suave, sem encostar dentes no lábio inferior.
- **Voz 100% Oral:** Toda vogal antes de N/M sai totalmente limpa pela boca antes do toque consonantal (`pan` sai oral limpo antes do toque dental, nunca "pão").

### 4.5 Italiano (`it_pt`)
- **Consoantes Duplas / Geminadas:** Reter o ar e segurar a musculatura pelo dobro do tempo na consoante dobrada antes de liberar a vogal seguinte (`pál-la`, `nót-te`, `kôn-tchét-to`).
- **Família do C e G:** C antes de E/I tem estalo de `tch` (`tcháo`); CH antes de E/I é K duro (`per-kê`). G antes de E/I tem estalo de `dj` (`dje-lá-to`); GH antes de E/I é G duro de gato (`spa-guét-ti`).
- **Família do SC:** SC antes de E/I é chiado contínuo suave `ch` (`chê-na`); SCH antes de E/I quebra o chiado e vira `sk` duro (`brus-két-ta`).
- **Letra Z e ZZ Africadas:** Nunca tem som de abelha frouxo. É estalo seco `ts` (`pít-tsa`, `grát-tsie`) ou sonoro `dz` (`dzê-ro`).
- **Proibição de Redução Vocálica:** Vogais finais soam completas, abertas e firmes (`nót-te`, `a-mí-ko`), sem anasalar antes de N/M.
- **T e D Secos:** Ponta da língua reta atrás dos dentes sem chiar como 'tchi' ou 'dji' (`ti á-mo`, `mat-tí-na`).

### 4.6 Alemão (`ge_pt`)
- **Umlauts Ö e Ü:**
  - `ö` / `öö`: Língua posicionada para falar 'Ê' ou 'É', lábios projetados em bico redondo de 'Ô' ou 'Ó' (`schön`, `können`).
  - `ü` / `üü`: Lábios em bico fechado e firme de 'U', língua na frente para dizer 'I' agudo (`Tür`, `fünf`).
- **Inversão Crítica W vs V:** A letra W soa obrigatoriamente como 'V' do português (`Wasser` -> `vás-sa`). A letra V nativa soa como 'F' (`Vater` -> `fáa-ta`, `viel` -> `fíil`).
- **O 'R' Vocalizado:** No final `-er` e após vogais longas, não se raspa a garganta: morre como um 'a' curto e relaxado (`Wasser` -> `vás-sa`, `wir` -> `víia`).
- **Desvozeamento Final (Auslautverhärtung):** No final de palavras ou sílabas, B vira P seco, D vira T seco e G vira K seco (`ab` -> `ap`, `und` -> `unt`, `Tag` -> `táak`).
- **Golpe de Glote (Knacklaut):** Palavras iniciadas por vogal exigem um microbloqueio na laringe, nascendo com ataque seco independente, grafado com apóstrofo no *Leia::* (`ein Apfel` -> `áin 'áp-fel`).
- **Letra Z:** Soa estritamente como estalo seco `ts` colado (`Zeit` -> `tsáit`), sem vibrar como abelha.

function chamarGeminiCascata(payload, tInicio) {
  const modelCandidate = CONFIG.GEMINI_MODELS[0];
  const chaves = CONFIG.GEMINI_API_KEYS || [CONFIG.GEMINI_API_KEY];

  for (let attempt = 1; attempt <= 5; attempt++) {
    if (new Date() - tInicio > 360000) {
      throw new Error("Tempo limite de 6 minutos atingido");
    }

    let todasCom429 = true;

    for (let k = 0; k < chaves.length; k++) {
      const chaveAtual = chaves[k];
      const url = `https://generativelanguage.googleapis.com/v1beta/models/${modelCandidate}:generateContent?key=${encodeURIComponent(chaveAtual)}`;

      Logger.log(`[GEMINI] Testando Chave ${k + 1}/${chaves.length} com ${modelCandidate} (Ciclo ${attempt})...`);

      try {
        const response = UrlFetchApp.fetch(url, {
          method: "post",
          contentType: "application/json",
          payload: JSON.stringify(payload),
          muteHttpExceptions: true
        });

        const code = response.getResponseCode();

        if (code === 200) {
          const json = JSON.parse(response.getContentText());
          let rawText = json.candidates[0].content.parts[0].text.trim();
          rawText = rawText.replace(/^```json\s*/i, "").replace(/```$/i, "").trim();
          
          // Remove vírgulas sobressalentes (trailing commas)
          rawText = rawText.replace(/,(\s*[\}\]])/g, "$1");

          Logger.log(`[GEMINI SUCESSO] Resposta gerada via Chave ${k + 1}.`);
          return JSON.parse(rawText);
        } else if (code === 429) {
          Logger.log(`[GEMINI 429] Chave ${k + 1} sem cota ou bloqueada (HTTP 429). Alternando para a próxima...`);
        } else {
          todasCom429 = false;
          Logger.log(`[GEMINI] Chave ${k + 1} retornou HTTP ${code}.`);
        }
      } catch (e) {
        todasCom429 = false;
        Logger.log(`[GEMINI] Falha na Chave ${k + 1}: ${e.message}`);
      }
    }

    // Se passou por todas as chaves da lista e nenhuma funcionou
    if (attempt < 5) {
      Logger.log(`[GEMINI] Todas as chaves falharam no ciclo ${attempt}. Pausando 60s antes de tentar novamente...`);
      Utilities.sleep(60000);
    }
  }

  Logger.log(`[GEMINI ERRO CRÍTICO] Nenhuma chave de API conseguiu gerar a resposta.`);
  return null;
}

function obterFrasesSupabase(par, nivel, topico) {
  const partes = par.split("_");
  const estudo = partes[0];
  const origem = partes[1];
  const colTopicOrigem = `topic_${origem}`;

  const url = `${CONFIG.SUPABASE_URL}/rest/v1/sentences?level=eq.${encodeURIComponent(nivel)}&${colTopicOrigem}=eq.${encodeURIComponent(topico)}&order=id.asc`;
  const options = {
    method: "get",
    headers: {
      "apikey": CONFIG.SUPABASE_KEY,
      "Authorization": `Bearer ${CONFIG.SUPABASE_KEY}`,
      "Accept": "application/json"
    },
    muteHttpExceptions: true
  };

  const response = UrlFetchApp.fetch(url, options);
  if (response.getResponseCode() !== 200) {
    throw new Error(`Falha ao consultar frases no Supabase: HTTP ${response.getResponseCode()}`);
  }

  const dados = JSON.parse(response.getContentText());
  const ehMandarim = (estudo === "zh" || estudo === "pi");

  return dados.map(f => {
    const item = {
      id: f.id,
      [origem]: f[origem]
    };
    if (ehMandarim) {
      item.zh = f.zh;
      item.pi = f.pi;
    } else {
      item[estudo] = f[estudo];
    }
    return item;
  });
}

function obterMatrizSupabase(par) {

function processarProximoTopico() {

LOTE DE FRASES DO TÓPICO A PROCESSAR:

    planilha.getRange(linhaAlvo, 7).setValue(`Erro: ${err.message} (${duracaoFormatada})`);
  } finally {

    const statusFinal = planilha.getRange(linhaAlvo, 5).getValue();
    if (statusFinal !== "Concluído") {
      planilha.getRange(linhaAlvo, 5).setValue("Pendente").setBackground("#f4cccc");
    }
  }
}

1. Vogal U (tu, rue, une)
Como fazer: Monte os lábios em bico fechado e firme de falar "U", mas posicione a língua para dizer "I". O som sai agudo e brilhante. O símbolo ü representa exatamente esse "I" pronunciado com bico de "U".
Trava da L1: Não desfaça o bico nem relaxe os lábios para o "U" comum do português.
Grafia no Leia:: ü (tü, rü, ün, sälü).
2. Contraste OU vs. U (vous / vu, dessous / dessus)
Como fazer: O encontro "OU" é exatamente o "U" natural do português (vous, dessous). Já a letra "U" isolada exige o bico firme dizendo "I", representada pelo símbolo ü (vu, dessus).
Trava da L1: Não pronuncie os dois iguais; trocar o som altera completamente o sentido da palavra (dessous = embaixo; dessus = em cima).
Grafia no Leia:: u para OU (vu, dê-su) vs. ü para U (vü, dê-sü).
3. Vogal EU / ŒU Fechada (deux, peu, bleu, vœu)
Como fazer: Posicione a boca para falar "Ê", mas projete os lábios para a frente em bico redondo e fechado, mantendo o som travado e estável. O símbolo ø representa exatamente esse "Ê" emitido com bico redondo.
Trava da L1: Não leia como o ditongo "ê-u" do português nem abra os cantos da boca em "é". É uma nota vocálica única e fixa.
Grafia no Leia:: ø (dø, pø, blø, vø).

Como fazer: Posicione a língua para falar a letra "É" bem aberta, mas arredonde os lábios para a frente no formato de "Ó", deixando a cavidade bucal oca. O símbolo œ representa exatamente esse "É" emitido com lábios em "Ó".
Trava da L1: Não leia as letras separadas ("o-e") e não substitua por "é" ou "ó" puros. Ocorre quase sempre quando há consoante falada na mesma sílaba (r, n, l, f).
Grafia no Leia:: œ (sœr, kœr, jœn, pœr, œr).

Como fazer: Solte a mandíbula para baixo, deixe a língua frouxa e emita um som vocálico neutro, curtíssimo e sem esforço muscular. O símbolo ə representa essa vogal central e relaxada, emitida quase sem peso.
Trava da L1: Não coloque força de "ê" fechado ("JÊ", "DÊ") e nunca transforme em "i" brasileiro ("ji", "dji").
Grafia no Leia:: ə (lə, jə, də, mə, sə).

Como fazer:
Som fechado (ê): estique os cantos da boca em meio sorriso firme e emita o som de "ê" fechado de você (parlé, café, été).
Som aberto (é): abaixe o queixo abrindo bem a boca na vertical e emita o som de "é" aberto de pé (parlais, lait, fête, merci).
Trava da L1: No encontro "ai" (lait, parlais), não faça o ditongo "ái" do português; trata-se de um som puro de "é" aberto. Em finais fechados (parler, parlé), nunca adicione som de "i" ("par-lêi").
Grafia no Leia:: ê para som fechado (par-lê, ka-fê, ê-tê) vs. é para som aberto (par-lé, lé, fét).
7. Encontro AU / EAU (beau, eau, auto, chaud, bateau)
Como fazer: Projete os lábios em círculo redondo firme e emita um som de "ô" bem fechado, puro e constante.
Trava da L1: Não leia as letras separadas ("a-u", "e-a-u") e nunca deslize para o som de "u" no fim da sílaba (não fale "bôu", o som é "ô" travado).
Grafia no Leia:: ô (bô, ô, ô-tô, chô, ba-tô, rês-tô-ran).
8. Encontro OI (moi, toi, soir, trois, boire)
Como fazer: Projete um bico rápido de semivogal "u" e abra imediatamente para a vogal "a", gerando um bloco sonoro único de "uá".
Trava da L1: Não leia as letras separadas como "ó-i" nem acrescente som de "i" no final (nunca fale "mó-i").
Grafia no Leia:: uá (muá, tuá, suár, truá, buár).
9. A Semivogal U Diante de Vogal (huit, nuit, suis, cuisine, lui)
Como fazer: Arme os lábios no bico fechado do "U" francês (ü) e deslize imediatamente para a vogal "i" em um único golpe contínuo. A grafia üí representa essa transição rápida saindo do bico tenso direto para o "i".
Trava da L1: Não use o nosso "w" relaxado de uísque nem pronuncie "u-i" solto. É obrigatório travar o bico firme do ü antes de disparar o "i".

-el final (/l̩/): suba a ponta da língua firme nos dentes superiores mantendo o som claro e consonantal de L (Apfel, Dunkel).
Trava da L1: O "E" final nunca vira "I" (bitte é bɪ́t-te, nunca "bíti"; habe é háa-be, nunca "hábi"). E em -el, a língua tem que tocar fisicamente no dente superior, sem virar som de "U" (Apfel não é "ápfeu").
Grafia no Leia:: e neutro (bɪ́t-te, háa-be, dán-ke), -en seco (kóm-men, gêe-ben) e -el dental (áp-fel, dʊ́n-kel).

Como fazer: Espalme o meio da língua contra a parte da frente do céu da boca enquanto abre os lábios em um sorriso tenso e bem puxado para os lados. Solte um estalo seco, fino e agudo, sem ar e sem voz.
Trava da L1: Nunca leia com som de "J" do português (janela, jogo). A letra J do mandarim é um estalo seco com a boca em sorriso, sem vibração de voz na garganta e sem sopro de ar. Também não curve a língua para trás.
Grafia no Leia:: dj com a boca em sorriso tenso (djī, djiā, djiàn, djīng, djiôu).
21. A Série Palatal Q: O Estalo com Explosão de Ar e Sorriso Espalmado (/tɕʰ/) (qī, qù, qián, qǐng, qiú)
Como fazer: Espalme o meio da língua contra a frente do céu da boca duro com os cantos dos lábios puxados em sorriso bem aberto e tenso (mesma posição do J). No momento da soltura, dispare uma rajada forte, intensa e audível de ar soprado para fora.
Trava da L1: Nunca leia com som de "K" ou "QU" do português (quarto, queijo). A letra Q do mandarim nunca tem som de K; soa parecido com "TCH", mas articulado com sorriso esticado e disparando uma forte explosão de ar.
Grafia no Leia:: tch com a boca em sorriso espalmado (tchī, tchü, tchiên, tchǐng, tchiôu).
22. A Série Palatal X: O Chiado Fino e Agudo (/ɕ/) (xī, xià, xiǎo, xīng, xué)
Como fazer: Deixe os cantos da boca esticados em sorriso bem aberto e aproxime o meio da língua do céu da boca, deixando apenas uma passagem estreita. Solte o ar de forma contínua, gerando um chiado fino, agudo e sibilante (como um gato bufando ou assoprando com um sorriso forçado).
Trava da L1: Não faça o chiado abafado ou oco do "X" comum do português com a boca relaxada (lixo, chácara). O som do X no mandarim é agudo, frontal e sibilante, exigindo obrigatoriamente o sorriso aberto.
Grafia no Leia:: x com a boca em sorriso esticado (xī, xià, xiǎo, xīng, xüé).
23. O "E" Gutural Posterior em Sílabas Abertas (/ɤ/) (hē, de, gē, le, kè)
Como fazer: Deixe a boca entreaberta e os lábios completamente relaxados (sem fazer bico e sem esticar em sorriso). Emita o som vocálico puxado lá do fundo da garganta, mantendo a língua recuada. O som é fechado e gutural, ficando entre um "a" e um som engolido no fundo da laringe.
Trava da L1: Não abra a boca para fazer "É" aberto e não faça o "Ê" frontal comum do português (leite, pé). A vogal E isolada no mandarim nunca é frontal; o som precisa ressoar lá atrás na garganta, muito próximo do som de um A.
Grafia no Leia:: a ou ga/ka com som gutural fechado (rrā, da, gā, la, kà).
24. O "I" Apical Travado (Vogal Zero) após Z, C, S e ZH, CH, SH, R (zi, ci, si vs. zhi, chi, shi, ri)
Como fazer: Nestas sílabas específicas, a letra "I" não tem som de "I". Ela serve apenas para sustentar a vibração da própria consoante anterior:
Em zi, ci, si: mantenha a língua colada nos dentes da frente e sustente apenas o zumbido dental da consoante.
Em zhi, chi, shi, ri: mantenha a ponta da língua curvada para trás e sustente o som retroflexo com a língua e a boca imóveis.
Trava da L1: Não estique a boca para pronunciar a vogal "I" comum do português (zí, ssí, chí). Fazer o "I" tradicional aqui descaracteriza a palavra; a boca deve ficar travada na posição da consoante.
Grafia no Leia:: consoante adaptada com a indicação de som travado (tsï, chï, djï, jï).
25. A Vogal Ü com Bico e a Armadilha Ortográfica após J, Q, X, Y (nǚ, lǜ vs. jù, qù, xū, yuè)
Como fazer: Posicione os lábios em bico firme e redondo de "U", mas tente emitir a vogal "I" por dentro, sem desfazer nem relaxar o bico.
Trava da L1: Quando a letra U vem após J, Q, X, Y (ju, qu, xu, yu), a ortografia oficial do Pinyin elimina os dois pontinhos da trema, mas a pronúncia continua sendo obrigatoriamente Ü com bico. Nunca leia como o "U" comum do português.
Grafia no Leia:: ü obrigatório para forçar o bico do falante de português (nǚ, lǜ, djǜ, tchǜ, xǖ, yüè).
26. A Rima Retroflexa Isolada ER (/aɚ/ ou /ɚ/) (ēr, ér, ěr, èr, érzi)
Como fazer: Emita a vogal central entreaberta e, simultaneamente, curve a ponta da língua para trás em direção ao céu da boca, enrolando o som em um único movimento contínuo da laringe até a língua suspensa.
Trava da L1: Não leia como "é-r" ou "e-re" com a língua batendo na frente dos dentes, e nunca solte o som raspado da garganta do português (érr). A língua curva para trás no ar, no meio do palato, enquanto o som é emitido.
Grafia no Leia:: êr com indicação de língua curvada para trás (ēr, ér, ěr, èr, ér-tsï).
27. A Transição Labial Oculta em BO, PO, MO, FO ([wɔ]) (bō, pō, mǒ, fǒu)
Como fazer: Ao pronunciar essas sílabas, não salte direto dos lábios para a vogal "O" aberta. Faça uma transição labial suave passando por um "u" rápido antes do "o" ("buô", "puô", "muô", "fuô").
Trava da L1: O falante de português vê a letra "O" grafada sozinha e pronuncia de forma plana e seca como "bó", "pó", "mó". O mandarim exige a projeção redonda dos lábios com som de "uô".
Grafia no Leia:: uô na terminação da sílaba adaptada (buō, puō, muǒ, fuǒu).
28. O Falso Amigo da Rima -IAN / YAN ([jɛn]) (tiān, jiàn, xiān, yán)
Como fazer: Comece na semivogal "i" e deslize diretamente para um som de "ên" fechado, travando a ponta da língua firme atrás dos dentes superiores da frente para cortar o som a seco. Soa obrigatoriamente como "iên".
Trava da L1: Não leia ao pé da letra como "i-an" aberto do português (ti-an, xi-an). No mandarim padrão, a combinação de I com AN nunca abre em "an"; ela fecha sempre em "iên" com o N travado nos dentes.
Grafia no Leia:: iên na sílaba adaptada (tiēn, djièn, xiēn, ién).
29. A Rima -ÜE / YUE ([yɛ]) (yuè, jué, què, xué)
Como fazer: Monte os lábios em bico firme e redondo de "ü" e abra imediatamente para a vogal "é" aberta, sem desfazer a projeção dos lábios antes da hora. Soa exatamente como "üé".
Trava da L1: Não leia como "u-e" relaxado do português (quê, xue). Lembre-se de que após J, Q, X e Y a letra U é sempre o "ü" com bico, abrindo em "é" aberto e frontal.
Grafia no Leia:: üé forçando a marcação de bico (yüè, djüé, tchüé, xüé).
30. A Rima -ÜAN / YUAN ([yɛn]) (yuán, juǎn, quàn, xuǎn)
Como fazer: Comece com os lábios no bico fechado de "ü", deslize para a vogal "ên" e trave a ponta da língua atrás dos dentes superiores da frente para fechar o som a seco. Soa como "üên".
Trava da L1: Não leia como o ditongo aberto "uan" comum do português (quanto, quando). Lembre-se de que após J, Q, X e Y a letra U é sempre o "ü" com bico abrindo em "ên", com a língua colando no dente no final.
Grafia no Leia:: üên (üén, djüên, tchüèn, xüên).
31. O Ditongo com Vogal Oculta -IU / YOU ([joʊ]) (jiǔ, liù, xiū, yóu)
Como fazer: Comece na semivogal "i", passe por um som de "ô" fechado no meio e finalize recolhendo os lábios no "u". O som real de transição é "iôu".
Trava da L1: O falante de português lê a grafia do Pinyin "iu" direto, como em viu ou partiu. No mandarim, existe um "o" intermediário obrigatório: jiǔ não é "djiú", é "djiôu"; liù não é "liú", é "liôu".
Grafia no Leia:: iôu (djiôu, liôu, xiôu, iôu).
32. O Ditongo com Vogal Oculta -UI / WEI ([weɪ]) (duì, shuǐ, guì, wéi)
Como fazer: Comece com os lábios projetados em "u", passe por um "ê" fechado no meio e finalize no "i". O som real de transição é "uêi".
Trava da L1: O brasileiro lê a escrita "ui" direto, como em fui ou ruim. No mandarim, existe um "e" bem audível no centro: duì não é "dúi", é "duêi"; shuǐ não é "chúi", é "chuêi".
Grafia no Leia:: uêi (duêi, chuêi, guêi, uêi).
33. A Rima com Vogal Oculta -UN / WEN ([wən]) (lùn, chūn, zhǔn, wén)
Como fazer: Comece nos lábios com o som de "u", abra para a vogal "ên" fechada e trave a ponta da língua colada atrás dos dentes incisivos superiores no "N". Soa como "uên".
Trava da L1: Não leia como o som de "um" ou "on" do português (fundo, mundo). A terminação -un do Pinyin não é um "u" nasal simples; ela carrega um som de "e" no meio ("uên") com corte firme da língua nos dentes.
Grafia no Leia:: uên (luên, tchuên, djuên, uên).
34. A Armadilha de Grafia da Rima -ÜN / YUN ([yn]) (jūn, qún, xùn, yún)
Como fazer: Mantenha os lábios em bico firme e redondo de "ü", emita a vogal nasalizada e cole a ponta da língua atrás dos dentes da frente para cortar o som a seco no "N". Soa exatamente como "ün".
Trava da L1: Não confunda com a rima anterior (-un / uên). Quando escrito após J, Q, X e Y, a letra U é sempre o "ü" de bico. A palavra qún nunca é "tchuên" nem "kum": é "tchün".
Grafia no Leia:: ün (djün, tchün, xün, ün).
35. A Rima -UAN / WAN Aberta ([wan]) (guān, kuǎn, huán, wán)
Como fazer: Comece na projeção dos lábios em "u", abra a boca em um "a" límpido e termine colando a ponta da língua atrás dos dentes superiores da frente para fechar no "N". Soa como "uan" com corte dental firme.
Trava da L1: Não deixe o som nasalizado e solto como no português (lã, cã), onde a vogal morre pelo nariz sem a língua tocar o dente. A ponta da língua precisa subir e bloquear o ar atrás dos dentes da frente. E nunca confunda com as sílabas de J, Q, X, Y (que usam o bico de üên).
Grafia no Leia:: uan com corte dental (guān, kuǎn, rruán, uán).
36. Oposição Nasal Dental vs. Velar: -AN vs. -ANG (bān vs. bāng, kàn vs. kàng, tiān vs. yáng)
Como fazer:
-AN: abra a boca na vogal "a" e cole a ponta da língua firme contra os dentes superiores da frente, bloqueando a saída de ar pela boca para cortar o som a seco pelo nariz ("an" frontal e travado).
-ANG: abra a boca mais para trás ("á" amplo) e suba a raiz da língua contra o céu da boca mole, deixando o ar ressoar amplo na garganta sem encostar a ponta da língua em lugar nenhum ("ang" aberto e profundo).
Trava da L1: No português, o falante nunca encosta a ponta da língua no dente ao falar palavras nasais como fã, lã ou canto. No mandarim, se você não cravar a ponta da língua nos dentes em -AN, a palavra vira -ANG e muda totalmente o significado.
Grafia no Leia:: an com corte dental nos dentes da frente (bān, kàn, tiā
n) vs. ang com ressonância aberta no fundo da garganta (bāng, kàng, yáng).
37. Oposição Nasal Dental vs. Velar: -EN vs. -ENG (bēn vs. bēng, hěn vs. hěng, rén vs. réng)
Como fazer:
-EN: emita a vogal fechada "ên" e imediatamente trave a ponta da língua colada atrás dos dentes incisivos superiores, fechando o som com corte mecânico no dente.
-ENG: emita a vogal "ên" recuando a língua e encostando o dorso lá no céu da boca mole, mantendo a ponta da língua abaixada e solta, ressoando o som na garganta e no nariz.
Trava da L1: Pronunciar ambos como o "em/ên" nasal frouxo do português (sem, tempo), onde a língua fica flutuando no meio da boca. No mandarim, a oposição entre fechar a língua no dente (hěn) ou vibrar na garganta (hěng) separa palavras completamente distintas.
Grafia no Leia:: ên com corte dental (bēn, rrên, jên) vs. êng com ressonância no fundo (bēng, rrěng, jêng).
38. Oposição Nasal Dental vs. Velar: -IN vs. -ING (jīn vs. jīng, pín vs. píng, xìn vs. xìng)
Como fazer:
-IN: emita a vogal "i" com os cantos dos lábios em sorriso e cole a ponta da língua atrás dos dentes superiores no "N", cortando o som frontalmente a seco.
-ING: emita a vogal "i" e jogue a ressonância para o fundo da garganta, elevando a parte de trás da língua contra o céu da boca mole sem encostar a ponta da língua nos dentes.
Trava da L1: No português brasileiro, o N final morre apenas como uma nasalização solta (pudim, fim). No mandarim, a diferença entre jīn (hoje) e jīng (capital) depende exclusivamente de bater a língua na frente ou prender o som lá atrás.
Grafia no Leia:: in com corte dental (djin, pín, xìn) vs. ing com ressonância de fundo (djing, píng, xìng).
39. A Rima Posterior -ONG / YONG ([ʊŋ] / [jʊŋ]) (zhōng, dōng, hóng, yòng, qióng)
Como fazer:
-ONG: projete os lábios em bico redondo de "ô" fechado e faça o som ressoar cavernoso no fundo da garganta, com o fundo da língua bloqueando o céu da boca mole.
YONG / -IONG: inicie com um deslize rápido pela semivogal "i" e caia direto no "ông" ressonante no fundo da laringe ("iông").
Trava da L1: Não abra o som como o "om/on" comum do português (som, bom) e não solte duas sílabas separadas. O som precisa ser abafado, escuro e vibrar estritamente no fundo da cavidade bucal.
Grafia no Leia:: ông (djông, dông, rrông) e iông (yông, tchiông).
40. A Rhotacização do Mandarim (Erhua / 儿化 - Sufixo -r) (huàr, yìdiǎnr, nǎr, wánr)
Como fazer: Quando uma sílaba recebe o sufixo coloquial -r, não se cria uma nova sílaba. No final da vogal base, curve bruscamente a ponta da língua para trás em direção ao céu da boca em um único movimento contínuo de expiração. Se a palavra original terminar em -n ou -i, esse som final cai e a língua curva diretamente a partir da vogal.
Trava da L1: Nunca tente pronunciar como uma sílaba separada ("huá-ér") e nunca use o som raspado da garganta do português ("huá-rr"). Trata-se de uma flexão rápida da ponta da língua para trás no final da própria palavra.
Grafia no Leia:: sílaba fundida terminada em r com a língua curvada (rruár, yì-diêr, nǎr, uár).
45. O Apóstrofo Divisor Silábico (Xī'ān, tiān'ānmén, pí'ǎo)
Como fazer: Quando uma sílaba iniciada pelas vogais a, o, e vem imediatamente após outra sílaba sem consoante entre elas, o Pinyin usa um apóstrofo. Faça uma pausa milimétrica com corte de ar na garganta antes de iniciar a vogal seguinte, sem colar os sons.
Trava da L1: O falante de português aglutina tudo em uma corrida só: lê Xī'ān como se fosse uma sílaba única (xiēn), ou junta a consoante final na vogal seguinte em tiān'ān. A pausa curta é obrigatória para não fundir palavras distintas.
Grafia no Leia:: separação explícita com hífen no lugar do apóstrofo (Xī-ān, tiēn-ān-mên, pí-ǎo).

def sanitizar_palavra_audio(palavra):
    p = (palavra or "").strip().lower().replace("ß", "ss")
    sem_pontuacao = re.sub(r'[.,!?;:¿¡"“”`{}()[\]\-—…，。！？；：、«»/\\~*]', '', p)
    sem_pontuacao = re.sub(r"['’]", "_", sem_pontuacao)
    if not sem_pontuacao:
        return ""

    nfd = unicodedata.normalize("NFD", sem_pontuacao)
    mapa_diacriticos = {
        "\u0300": "grave", "\u0301": "acute", "\u0302": "circ", "\u0303": "tilde",
        "\u0308": "uml", "\u0327": "ced", "\u0304": "macron", "\u030c": "caron"
    }

    base_chars, marcas = [], []
    ultimo_char_base = ""
    for char in nfd:
        if char in mapa_diacriticos:
            marcas.append(f"{ultimo_char_base}_{mapa_diacriticos[char]}")
        else:
            if not ("\u0300" <= char <= "\u036f"):
                base_chars.append(char)
                ultimo_char_base = char

    slug_base = re.sub(r"[^a-zA-Z0-9_-]", "", "".join(base_chars))
    if marcas:
        return f"{slug_base}_{'_'.join(marcas)}"
    return slug_base

    for fid, r_csv in sorted(csv_data.items()):

        txt_csv = (r_csv.get(idioma) or "").strip()
        txt_db = (r_db.get(idioma) or "").strip()
        if idioma == "zh":
            pi_csv = (r_csv.get("pi") or "").strip()
            pi_db = (r_db.get("pi") or "").strip()
            if txt_csv != txt_db or pi_csv != pi_db:
                alteracoes_db[fid] = {"zh": txt_csv, "pi": pi_csv}
        else:
            if txt_csv != txt_db:
                alteracoes_db[fid] = {idioma: txt_csv}

    if not alteracoes_db:
        print("✔ Nenhuma alteração pendente de gravação no banco de dados.")
        return

    print(f"Atualizando {len(alteracoes_db)} registros na tabela sentences via PATCH...")
    headers_patch = {
        "apikey": SUPABASE_KEY,
        "Authorization": f"Bearer {SUPABASE_KEY}",
        "Content-Type": "application/json",
        "Prefer": "return=minimal"
    }

    db_sucessos = 0
    total_db = len(alteracoes_db)
    t_inicio_db = time.time()
    for fid, payload in alteracoes_db.items():
        url_patch = f"{SUPABASE_URL}/rest/v1/sentences?id=eq.{fid}"
        req_patch = urllib.request.Request(url_patch, data=json.dumps(payload).encode("utf-8"), headers=headers_patch, method="PATCH")
        for _ in range(3):
            try:
                with urllib.request.urlopen(req_patch, timeout=15) as resp:
                    if resp.status in (200, 204):
                        db_sucessos += 1
                        break
            except Exception:
                pass

        decorrido = time.time() - t_inicio_db
        taxa = db_sucessos / decorrido if decorrido > 0 else 0
        m, s = int(decorrido // 60), int(decorrido % 60)
        pct = (db_sucessos / total_db) * 100
        sys.stdout.write(f"\r  -> Banco: {db_sucessos}/{total_db} ({pct:.1f}%) | Tempo: {m:02d}:{s:02d} | {taxa:.1f} req/s")
        sys.stdout.flush()
    print()

    if db_sucessos != total_db:
        print(f"[ERRO] Falha ao atualizar sentences: {db_sucessos}/{total_db} frases sincronizadas.")
        sys.exit(1)

    print(f"✔ Supabase DB atualizado: {db_sucessos}/{total_db} frases sincronizadas com sucesso!")

    versao_anterior = obter_versao_atual_supabase(idioma)
    nova_versao = versao_anterior + 1
    ids_alterados = sorted(list(alteracoes_db.keys()))

    payload_rev = {
        "versao": nova_versao,
        "idioma": idioma,
        "ids_alterados": ids_alterados,
        "descricao": "",
        "tipo": "texto"
    }

    headers_post = {
        "apikey": SUPABASE_KEY,
        "Authorization": f"Bearer {SUPABASE_KEY}",
        "Content-Type": "application/json",
        "Prefer": "return=minimal"
    }

    req_post = urllib.request.Request(f"{SUPABASE_URL}/rest/v1/curso_revisoes", data=json.dumps(payload_rev).encode("utf-8"), headers=headers_post, method="POST")
    with urllib.request.urlopen(req_post, timeout=15) as resp_post:
        if resp_post.status not in (200, 201):
            print(f"[ERRO] Falha ao registrar versão: HTTP {resp_post.status}")
            sys.exit(1)

    print(f"✔ Versão {nova_versao} (tipo: texto) registrada no Supabase para [{idioma.upper()}]!")
    print(f"  - Total de IDs afetados: {len(ids_alterados)}")

function validarTextoSemJargao(texto) {
  const textoMin = texto.toLowerCase();
  for (const termo of PALAVRAS_PROIBIDAS) {
    // Procura o termo como palavra isolada para não travar em palavras como "principal"
    const regex = new RegExp(`\\b${termo.toLowerCase()}\\b`, 'i');
    if (regex.test(textoMin)) {
      return { valido: false, termo };
    }
  }
  return { valido: true };
}

async function processarTopico(nivel, nomeTopico, frasesTopico, pastaDestino) {
  const nomeArquivo = `${nivel}_${nomeTopico}.json`;
  const caminhoArquivo = path.join(pastaDestino, nomeArquivo);

  // Checkpoint: pula arquivos já gerados com todas as frases (a menos que um tópico específico tenha sido solicitado)
  if (!FILTRO_TOPICO && fs.existsSync(caminhoArquivo)) {
    try {
      const conteudo = JSON.parse(fs.readFileSync(caminhoArquivo, 'utf-8'));
      if (Object.keys(conteudo).length >= frasesTopico.length) {
        console.log(`[Checkpoint] Pulando '${nomeArquivo}' (já completo com ${frasesTopico.length} frases).`);
        return;
      }
    } catch (e) { }
  }

  console.log(`\n======================================================`);
  console.log(`Iniciando Tópico: [${nivel}] ${nomeTopico} (${frasesTopico.length} frases)`);
  console.log(`======================================================`);

  const resultadoTopico = {};
  const TAMANHO_LOTE = 6;

  for (let i = 0; i < frasesTopico.length; i += TAMANHO_LOTE) {
    const lote = frasesTopico.slice(i, i + TAMANHO_LOTE).map(f => {
      const item = {
        id: f.id,
        [IDIOMA_ORIGEM]: f[IDIOMA_ORIGEM]
      };
      if (IDIOMA_ESTUDO === 'zh' || IDIOMA_ESTUDO === 'pi') {
        item.zh = f.zh;
        item.pi = f.pi;
      } else {
        item[IDIOMA_ESTUDO] = f[IDIOMA_ESTUDO];
      }
      return item;
    });

    const loteNum = Math.floor(i / TAMANHO_LOTE) + 1;
    const totalLotes = Math.ceil(frasesTopico.length / TAMANHO_LOTE);
    console.log(`  -> Processando lote ${loteNum}/${totalLotes} (frases ${i + 1} a ${Math.min(i + TAMANHO_LOTE, frasesTopico.length)})...`);

    const resultadoLote = await chamarGemini(lote);
    Object.assign(resultadoTopico, resultadoLote);

    // Pausa preventiva de 6 segundos entre lotes para respeitar a cota de 10 RPM
    await aguardar(6000);
  }

  fs.writeFileSync(caminhoArquivo, JSON.stringify(resultadoTopico, null, 2), 'utf-8');
  console.log(`✔ Arquivo salvo com sucesso: ${nomeArquivo}`);
}

async function iniciarEsteira() {
  const parIdiomas = `${IDIOMA_ESTUDO}_${IDIOMA_ORIGEM}`;
  const pastaDestino = path.resolve(__dirname, `../public/explicacoes/${parIdiomas}`);
  if (!fs.existsSync(pastaDestino)) {
    fs.mkdirSync(pastaDestino, { recursive: true });
  }

  const colTopicOrigem = `topic_${IDIOMA_ORIGEM}`;
  const NIVEIS = ['A1', 'A2', 'B1', 'B2'];
  const colunasAlvo = (IDIOMA_ESTUDO === 'zh' || IDIOMA_ESTUDO === 'pi') ? 'zh, pi' : IDIOMA_ESTUDO;
  const colunaFiltro = (IDIOMA_ESTUDO === 'zh' || IDIOMA_ESTUDO === 'pi') ? 'zh' : IDIOMA_ESTUDO;

  for (const nivel of NIVEIS) {
    console.log(`\n>>> Carregando frases do nível ${nivel} (${parIdiomas}) do Supabase...`);

    const colunas = `id, ${colunasAlvo}, ${IDIOMA_ORIGEM}, level, ${colTopicOrigem}`;
    const { data, error } = await supabase
      .from('sentences')
      .select(colunas)
      .eq('level', nivel)
      .not(colunaFiltro, 'is', null)
      .order('id', { ascending: true });

    if (error) {
      console.error(`Erro ao buscar dados do nível ${nivel}:`, error);
      continue;
    }

    // Agrupa as frases nos tópicos da língua nativa do aluno
    const topicosDoNivel = {};
    for (const f of data) {
      const tp = f[colTopicOrigem];
      if (!tp) continue;
      if (!topicosDoNivel[tp]) topicosDoNivel[tp] = [];
      topicosDoNivel[tp].push(f);
    }

    for (const [nomeTopico, frases] of Object.entries(topicosDoNivel)) {
      if (FILTRO_TOPICO && !nomeTopico.toLowerCase().includes(FILTRO_TOPICO.toLowerCase())) {
        continue;
      }
      await processarTopico(nivel, nomeTopico, frases, pastaDestino);
    }
  }

  console.log('\n======================================================');
  console.log('ESTEIRA CONCLUÍDA: Todos os tópicos foram processados!');
  console.log('======================================================');
}

    sem_pontuacao = re.sub(r'[.,!?;:¿¡"“”`{}()[\]\-—…，。！？；：、«»/\\~*]', '', p)
    sem_pontuacao = re.sub(r"['’]", "_", sem_pontuacao)
    if not sem_pontuacao:
        return ""

    nfd = unicodedata.normalize("NFD", sem_pontuacao)
    mapa_diacriticos = {
        "\u0300": "grave",
        "\u0301": "acute",
        "\u0302": "circ",
        "\u0303": "tilde",
        "\u0308": "uml",
        "\u0327": "ced",
        "\u0304": "macron",
        "\u030c": "caron"
    }

    base_chars = []
    marcas = []
    ultimo_char_base = ""

    for char in nfd:
        if char in mapa_diacriticos:
            marcas.append(f"{ultimo_char_base}_{mapa_diacriticos[char]}")
        else:
            if not ("\u0300" <= char <= "\u036f"):
                base_chars.append(char)
                ultimo_char_base = char

    slug_base = re.sub(r"[^a-zA-Z0-9_-]", "", "".join(base_chars))
    if marcas:
        return f"{slug_base}_{'_'.join(marcas)}"
    return slug_base
